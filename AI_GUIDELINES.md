# AI guidelines

This project is built with AI assistance. What that means, and what we expect
from contributions:

- **Code** is mostly AI-written, but every change is strictly reviewed by a
  human before it is merged.
- **Docs** are AI-generated in the same way, and reviewed by a human.
- **Commit messages** are AI-generated.

## Contributing

AI-generated issues and pull requests are welcome, as long as:

- the code has been **thoroughly reviewed by a human** — you, before you open
  the PR. Don't submit code you haven't read and understood yourself;
- the issue or PR description is **concise**: what it's about and why, not a
  generated wall of text.
